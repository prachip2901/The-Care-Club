## 📌 Project Overview
**The Care Club** is a donation-based web application built using **Python (Django)** and **MySQL database**.  
It connects users with social service categories like hospitals, old age homes, schools, and social organizations.  
The system ensures transparent donation tracking, membership management, and admin control.

---

## ✨ Features

### 🏠 User Side
- Home page with navigation bar (Home, About Us, Categories)
- Donation categories:
  - Hospital Services
  - Old Age Home
  - Social Service
  - School Donations
- Secure online donations using **Razorpay Payment Gateway**
- Membership request system for users

---

### 🧑‍💼 Membership System
- Users can send membership requests
- Admin can **Approve / Reject** requests
- After approval:
  - User receives email with **username & password**
  - User becomes a registered member

---

### 🛠️ Admin Panel
- Secure admin login/logout
- Dashboard management:
  - View all donations
  - Track donation amount (₹500, ₹1000, etc.)
  - Category-wise donation tracking
  - Total donation calculation
  - Total registered members
- Manage membership requests (Approve / Reject)
- Track each user’s donation history

---

## 💰 Donation System
- Integrated with **Razorpay Payment Gateway**
- Secure online payment system
- Stores donation details in **MySQL database**
- Tracks:
  - User details
  - Donation amount
  - Donation category
  - Payment status
